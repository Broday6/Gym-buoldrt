# Music

**In use (Heritage hero edit, v13 on):** `ondrosik-sunlit-groove.flac`, "Sunlit Groove" by Ondrosik
(Ondrej Rosik), 123 BPM, from his Free Music Catalog on the Internet Archive:
https://archive.org/details/Ondrosik-Free-music-catalog
(file: https://archive.org/download/Ondrosik-Free-music-catalog/Sunlit%20Groove.flac).
Chosen over "Peaceful" because Brody found that one too slow for an ad (13 Oct 2026). Beat times are in
`sunlit-groove-beats.json`; the groove's hi-hats drop in at 27.12 s, which the edit anchors to the
start of the "Heritage Timber" reveal (`timeline.py --anchor 27.12 --anchor-scene real`).

**Earlier (v4-v12):** `ondrosik-peaceful.flac`, "Peaceful" by Ondrosik, same catalog, beats in
`peaceful-beats.json`.

Licence (both): the item is marked CC0 1.0 (public domain dedication), and the composer's own licence
file (`ondrosik-license.html`, saved here as downloaded) allows use in videos and films, editing, syncing
to picture, monetised distribution with no royalties, and says attribution is welcome but not required.
