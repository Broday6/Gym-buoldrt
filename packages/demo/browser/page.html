Running here

  • Variant-level index. One document per buyable SKU, grouped to one card per product — so “black shutter” shows the black one.
  • Ranking cascade. Typos, then words matched, then field weight, then proximity, then exactness. Tie-breaks, not a blended score.
  • Dimension parsing. 4x6, 12ft, 3-1/2" are lifted out of the query and applied as filters.
  • Merchandising. Collections and badges from rules that cut across the category tree.
  • Zero-result rescue. A hopeless query still lands on products, and says what it did.

Needs a server

  • The merchandiser console — rule builder, badges, change history and undo.
  • Analytics — the dashboard is computed from recorded shopper behaviour.
  • Catalogue ingest — this page is handed documents a real ingest produced.
  • Recommendation rails — they read co-occurrence out of the event store.

About the catalogue

  • Generated to be messy on purpose: missing images, thin descriptions, uncategorised products, duplicate SKUs — the conditions a real feed arrives in.
  • Prices, finishes and dimensions are synthetic. The products are not real listings.
